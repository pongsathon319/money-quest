# ⚔️ KruIce Money Quest — ติดตั้งบน GitHub Pages

ภาพรวม: **หน้าแอป** อยู่บน GitHub Pages (โหลดทันที, เปิดเต็มจอแบบแอป) · **ข้อมูล** ยังอยู่ใน Google Sheet เดิม โดยมี Apps Script เป็น API อยู่เบื้องหลัง

```
iPhone (แอปบนหน้าจอโฮม)  ──►  GitHub Pages (index.html, รูป, ไอคอน)
          │
          └── อ่าน/เขียนข้อมูล ──►  Apps Script API  ──►  Google Sheet "บันทึกรายรับรายจ่าย"
```

ใช้เวลาประมาณ 15 นาที ทำครั้งเดียว

---

## ส่วน A — ตั้งค่า Apps Script ให้เป็น API (ทำบนคอม)

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script**
2. ในไฟล์ `Code.gs` ลบโค้ดเดิมทั้งหมด แล้ววางโค้ดจากไฟล์ **Code.gs** ชุดนี้ → กด 💾
   - ไฟล์ `Index` และ `Sprites` ของเวอร์ชันก่อน ลบทิ้งได้ (ไม่ใช้แล้ว)
3. **สร้างรหัสลับ:** ที่แถบด้านบน เลือกฟังก์ชัน **setupToken** → กด **▶ เรียกใช้**
   - ครั้งแรกจะขออนุญาตสิทธิ์ → อนุญาต (ถ้าเจอ “Google hasn't verified this app” กด *Advanced → Go to … (unsafe)* เพราะเป็นสคริปต์ของคุณเอง)
   - ด้านล่างจะขึ้น **บันทึกการดำเนินการ**: `รหัสลับของคุณ: xxxxxxxx…` → **คัดลอกเก็บไว้** (ห้ามแชร์ให้ใคร)
4. **Deploy:** มุมขวาบน **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่** → ⚙️ เลือก **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** ← ต้องเลือกอันนี้ เพื่อให้แอปบน GitHub เรียกได้ (ข้อมูลยังปลอดภัยเพราะต้องมีรหัสลับ)
   - กด **ทำให้ใช้งานได้** → คัดลอก **URL เว็บแอป** (ลงท้ายด้วย `/exec`)
5. ทดสอบ: เปิด URL นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `Money Quest API พร้อมใช้งาน ✅`

## ส่วน B — อัปโหลดแอปขึ้น GitHub Pages (ทำบนคอม)

1. สมัคร/ล็อกอิน **github.com**
2. มุมขวาบน **＋ → New repository**
   - Repository name: `money-quest` (ชื่อนี้จะอยู่ในลิงก์แอป)
   - เลือก **Public** (GitHub Pages ฟรีต้องเป็น Public — ในโค้ดไม่มีข้อมูลการเงินหรือรหัสลับ ปลอดภัย)
   - กด **Create repository**
3. ในหน้า repo ใหม่ กดลิงก์ **uploading an existing file**
4. แตกไฟล์ `money-quest-pages.zip` ในคอม แล้ว **ลากไฟล์และโฟลเดอร์ทั้งหมดข้างใน** ลงไป:
   `index.html`, `manifest.webmanifest`, `sw.js`, `README.md`, โฟลเดอร์ `img/`, โฟลเดอร์ `icons/`
   (ลากโฟลเดอร์ทั้งโฟลเดอร์ได้เลย — อย่าลากไฟล์ .zip)
5. กด **Commit changes**
6. ไปที่ **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/(root)** → **Save**
7. รอ 1–2 นาที รีเฟรชหน้า จะเห็นลิงก์ `https://<ชื่อผู้ใช้>.github.io/money-quest/`

## ส่วน C — ติดตั้งบน iPhone

1. เปิดลิงก์ GitHub Pages ใน **Safari**
2. กรอก **ลิงก์ API** (จากข้อ A4) และ **รหัสลับ** (จากข้อ A3) → **เชื่อมต่อ**
   - เคล็ดลับ: ส่งทั้งสองอย่างให้ตัวเองทาง LINE Keep / Notes แล้วคัดลอกวางบน iPhone
3. กดปุ่มแชร์ **⬆︎ → เพิ่มไปยังหน้าจอโฮม** → จะได้ไอคอน Money Quest เปิดเต็มจอเหมือนแอป
4. (ไม่บังคับ) ในแอป → ตั้งค่า → การแจ้งเตือน → เปิด แล้วกด “ทดสอบส่ง”

> ติดตั้งบน iPad/คอมเครื่องอื่นได้ด้วย กรอกลิงก์ API + รหัสลับเดียวกัน

---

## ทำไมเร็วขึ้น

- **เปิดแอป:** แสดงข้อมูลล่าสุดที่เก็บในเครื่องทันที แล้วซิงก์กับชีตเบื้องหลัง (ดูสถานะที่มุมบน: ซิงก์แล้ว / กำลังซิงก์ / รอส่ง)
- **บันทึก:** กดแล้วขึ้นทันที ไม่ต้องรอชีต แอปค่อยส่งขึ้นชีตเอง
- **ไม่มีเน็ต:** บันทึกได้ตามปกติ รายการจะรอส่งและส่งให้อัตโนมัติเมื่อกลับมาออนไลน์ (มีรหัสกันบันทึกซ้ำ)

## เมื่อต้องการแก้/อัปเดตแอป

- **แก้หน้าแอป:** อัปโหลดไฟล์ใหม่ทับใน GitHub (Add file → Upload files) และ **เปลี่ยนเลขเวอร์ชันในไฟล์ `sw.js`** (เช่น `mq-v1` → `mq-v2`) — iPhone จะได้ของใหม่ตอนเปิดแอปครั้งถัดไป (บางครั้งต้องปิดแล้วเปิดใหม่ 2 รอบ)
- **แก้ Code.gs:** Deploy → **จัดการการทำให้ใช้งานได้** → ✎ → เวอร์ชัน **ใหม่** → Deploy (ลิงก์ API เดิมใช้ต่อได้)

## ความปลอดภัย

- ใครก็ตามที่มีทั้ง **ลิงก์ API + รหัสลับ** จะอ่าน/เขียนชีตได้ เก็บทั้งสองอย่างไว้กับตัว
- ถ้าสงสัยว่ารหัสหลุด: รัน `setupToken` อีกครั้ง (รหัสเก่าจะใช้ไม่ได้ทันที) แล้วในแอป → ตั้งค่า → ตัดการเชื่อมต่อ → เชื่อมต่อใหม่ด้วยรหัสใหม่
- รหัสลับเก็บเฉพาะในเครื่องที่กรอก ไม่ได้อยู่ในไฟล์บน GitHub

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| “API ตอบกลับไม่ใช่ JSON” | Deploy ต้องเลือก **ทุกคน (Anyone)** และใช้ลิงก์ที่ลงท้าย `/exec` (ไม่ใช่ `/dev`) |
| “รหัสลับไม่ถูกต้อง” | คัดลอกรหัสใหม่จาก setupToken ให้ครบ ไม่มีช่องว่าง |
| เปิดลิงก์ GitHub แล้ว 404 | รอ 2–3 นาทีหลังตั้ง Pages และเช็กว่า `index.html` อยู่ชั้นนอกสุดของ repo (ไม่ได้อยู่ในโฟลเดอร์ย่อย) |
| แก้ไฟล์แล้วแอปยังเป็นของเก่า | เปลี่ยนเลขเวอร์ชันใน `sw.js` แล้วเปิดแอปใหม่ 2 รอบ |
